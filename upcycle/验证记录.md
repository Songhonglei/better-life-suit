## 验收反馈逐项修复与复测

1. **自由文本误禁剪刀** — `lib/planner.js` 改为按分句解析否定与允许，否定只作用于所在分句；明确允许的工具会加入可用工具并从文字禁用里排除；无法转成约束的分句才提示未生效。`lib/orchestrator.js` 的差异文案改用中文工具名。
   用用户原句「不能用胶水，剪刀可以用，预算20元」在接口层与浏览器层各复测一次：只禁用胶水，剪刀保留，预算 20 生效，步骤仍为「用剪刀沿划线剪开纸板」，不再退化成徒手撕纸板；界面显示「已按文字保留可用工具『剪刀』」，且不出现 `glue` / `scissors` / `demo`。

2. **瓶子环切后错误收边** — `lib/data/catalog.js` 给步骤变体加 `effect`（是否产生新切口）与 `when`（只在该状态下可用）；`lib/planner.js` 选择做法时向后检查后续步骤是否走得通，走不通就换不裁切做法，都走不通才明确判不可行。
   仅有美工刀时，三个瓶身方案都改用不裁切做法，收边文案与实际做法一致，并说明「没有胶带或剪刀给切口收边」；有胶带时仍走环切 + 真实贴胶带收边，没有被无差别改成不裁切。

3. **LLM 超时只覆盖响应头** — `lib/llm.js` 把计时器放进 `finally`，覆盖 `fetch` 到响应体完整读取（含错误体）；AbortError 统一转成可重试的 `llm_timeout`。`scripts/mock-llm.js` 新增 `stalled_body` 模式：先发 200 响应头、body 永不结束。实测 2505ms 返回 502 / `llm_timeout`，没有挂死。

4. **分享卡排版与标注** — `public/share.js` 改为固定分区，步骤区最后一行基线 1250、页脚分割线 1290；缩短的步骤明确标「步骤摘要」并注明共几步、完整做法见清单；示例模式卡片标「示例方案」。`buildCard` 改为异步，直接把详情页 `Art.renderDiagram` 生成的同一张 SVG 画进 Canvas（`diagramSource=detail-svg`），不再另画一套简化图；去掉与 SVG 自带角标重复的说明文字。PNG 目视复核无重叠、无叠字。

5. **界面文案与交互收敛** — 结果页示例说明只保留 notice 一处（标题下 meta 改为客观信息，模式徽标缩短）；物品/材质纠正表单默认收起、点击展开；常用工具 6 件直达，其余 7 件收进「更多工具（7）」，非常用但已选中的仍留在主区，折叠不丢选择；收藏列表、差异文案、清单里的内部 id 全部改中文。

### 经验教训：这个阶段最值钱的 7 条

1. **能力判断必须真发一次请求，不能看列表或文档下结论**。最大的一次翻车：只看 `/models` 里没有 `*-vl` 就断言「不支持视觉」，写进文档并据此关掉视觉；真发 `image_url` 后 `qwen3.8-flash` 准确识别「喷雾瓶 / 塑料」。同类还有：OCR 鉴权失败 ≠ 服务未开通（靠 STS `GetCallerIdentity` 才定位到运行角色是 `TCB_QcsRole`，不是 `SCF_QcsRole`）、网关 100 KiB 上限（用 100,035 / 102,435 字节两个 body 卡出边界）、域名 `limit 1`（预检才看到）、`CreateHostingDomain` 不是配额旁路（真调 API 才确认）。**规则：查能力用最小真调用，探平台限制用真实 payload 卡边界。**
2. **「不假装成功」是产品可信度的地基，比多加功能重要**。mock 不写成真实 LLM、`ocr.configured` 不等于有权限、`source=ocr / vision / llm` 分开标注、失败保留输入不静默降级、`verify-cloud-ocr` 默认断言 `mode=live`（空 `envVariables` 误部署会直接失败）。这条约束让每一次「通过」都有含义。
3. **退出码 0 / CLI 的「✔ Success」/ 管道输出都不算上线成功**。`deploy:live` 补了远端 `/api/config` 复核，静态资源逐个 md5 比对，本轮预览更新也独立 curl 比对 md5；`| tail` 会吞退出码，不能拿它判成败。
4. **单一真源 + 服务端重复校验**。`diagram.dims` 是尺寸唯一真源、`logo.svg` 是图标唯一真源、`PRODUCTS` 是门户唯一真源；模型给出的预算/工具方案服务端再校验一次，不信任前端。改一处不会长出第二份不一致。
5. **密钥与权限要有生命周期闭环，不是「用完记得删」**。部署瞬间注入 envVariables → 异步 spawn + SIGINT/SIGTERM/异常幂等还原 → 权限 600 → 模板残留即中止 → 远端自检；临时 `QcloudSSLFullAccess` 挂完申请证书立刻 `Detach` 并复查策略数 6→7→6。项目文件完整 Key 命中 0。
6. **增量上线不动存量**。子目录部署、不加 `--prune`、根首页/域名/路由一律不碰、先上 `portal-preview.html` 与 `/stock-review/` 子页做预览、原页备份在 `output/backup/`。所以前置条件做了半天，线上一直没中断过。
7. **护栏分层，且如实说清它不是硬防护**。前端压缩/超时 + 云函数限流 / `/diag` 缓存 + 明确文案；文档写死「单容器内存计数，容器回收即重置」。别把护栏对外说成防刷。

### 踩坑 → 规则速查

| 现象 | 根因 | 以后 |

### 可优化（按优先级，带「值不值得现在做」的判断）
